// how it works

Under the hood.

Everything Stays on Your PC

You pick a folder on your hard drive and that's where everything lives — worlds, settings, backups, all of it. Releu never sends anything off your machine. Not even anonymously.

Backups Saved Right on Your Drive

Releu zips up your entire server and saves it on your drive whenever you want. Griefer blew up spawn? Corrupted world? Roll it back in seconds. Works completely offline. Cloud backup — coming soon

Share With Anyone via playit.gg

Releu uses playit.gg to give your server a public address. Your friends just type it in Minecraft and they're in — no router settings, no static IP, no firewall rules. One toggle to turn it on.

Console & Mobile Players Welcome

Turn on crossplay and Releu installs and configures Geyser + Floodgate for you. Your friends on mobile, console, or Windows 10/11 can jump straight into your Java server — no extra steps on their end either.

// wait, is it safe?

Not a virus. Not sketchy.
Here's the proof.

We get it — random app off the internet that wants to run stuff on your PC sounds suspicious. Here's exactly what Releu is and isn't.

🦠 Is it a virus?

No. Releu is an open source desktop app. Every single line of code is public on GitHub — anyone can read it, audit it, or build it themselves from scratch. There's nothing hidden.

🔍 Why does my antivirus flag it?

Some antivirus software flags unsigned apps from indie developers as "suspicious" even when they're completely clean. This is a false positive. Releu doesn't have an expensive code signing certificate — it's a free open source project. The source code is right there if you want to verify it yourself.

📡 Does it phone home or track me?

No telemetry. No analytics. No usage tracking. Releu doesn't make any outbound connections except when you explicitly ask it to — like downloading a server JAR or connecting through playit.gg. It doesn't know who you are and doesn't try to find out.

🔑 Does it need admin / special permissions?

Releu only needs access to the folder you point it at for storing server files. It runs Java processes on your machine to power the Minecraft server — same as running the server manually yourself. No system-level access, no background services installed without your knowledge.

☕ What does it actually install?

Just the Releu app itself, and whatever Minecraft server software you pick (Vanilla, Paper, Fabric, etc.). If Java isn't already on your machine, Releu will prompt you to install it — that's a standard Microsoft/Eclipse requirement for running any Minecraft server, nothing unusual.

👀 Can I see the source code?

Yes, that's the whole point. The full source is on GitHub. Fork it, read it, run it locally from source if you want. Nothing is obfuscated or hidden behind a paid tier.
